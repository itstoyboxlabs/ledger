# Code of conduct

Be kind and assume good intent. Disagree about the code, not the person.

Not okay: harassment, insults, personal attacks, sharing other people's private information, or posting your own or
anyone else's real financial data.

Maintainers can edit or remove comments, issues and pull requests that break these rules, and can block people who
keep breaking them. To report a problem, email itstoyboxlabs@gmail.com.
